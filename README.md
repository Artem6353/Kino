# КАДР — кино и сериалы

Адаптивный демонстрационный каталог кино с поиском, фильтрами и окном плеера.

## Запуск
Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Возможности
- Адаптивная сетка для телефонов, планшетов и больших экранов.
- Поиск по названию и фильтры по типу/жанру.
- Демонстрационная подборка с постерами из TMDB.
- Окно плеера: можно вставить прямую ссылку MP4/WebM или URL внешнего embed-плеера.

## Важно
Это демонстрационный каталог, он не включает права на фильмы и не поставляет собственные видеопотоки. Воспроизведение зависит от корректной доступной ссылки; некоторые сайты запрещают встраивание через iframe. Постеры загружаются из внешних источников, поэтому для них требуется интернет.


## Источники и плеер
- Автопоиск в Internet Archive показывает встроенный материал только при явном признаке Public Domain / поддерживаемой Creative Commons-лицензии и совпадении названия и года. Метаданные каталога не являются юридической гарантией — проверяйте страницу материала.
- Ручной источник принимает HTTP/HTTPS embed URL, MP4/WebM/OGG и HLS (.m3u8). Для HLS используется встроенная поддержка браузера или hls.js с CDN.
- JustWatch, YouTube и Crunchyroll сейчас открываются как поисковые страницы, а не как API-интеграции и не гарантируют доступность тайтла.
- GitHub Pages — статический хостинг: секретные API-ключи нельзя хранить в HTML/JavaScript. Для API, требующих ключа, нужен отдельный серверный endpoint или serverless-функция с секретом в переменных окружения.
